# Lista de abreviaturas e siglas

| Sigla | Significado |
|---|---|
| A1, E1 | Fluxo alternativo e fluxo de exceção de um caso de uso (numerados em sequência) |
| ADR | Architecture Decision Record (registro de decisão de arquitetura) |
| ANPD | Autoridade Nacional de Proteção de Dados |
| API | Application Programming Interface (interface de programação de aplicações) |
| BPMN | Business Process Model and Notation |
| CPF | Cadastro de Pessoas Físicas |
| DDD | Domain-Driven Design (projeto orientado ao domínio) |
| DTO | Data Transfer Object (objeto de transferência de dados) |
| FB | Fluxo básico de um caso de uso |
| FK | Foreign Key (chave estrangeira) |
| HTTP | Hypertext Transfer Protocol |
| IA | Inteligência artificial |
| ID | Identificador |
| ISO | International Organization for Standardization |
| JSON | JavaScript Object Notation |
| JWT | JSON Web Token |
| LGPD | Lei Geral de Proteção de Dados Pessoais (Lei nº 13.709/2018) |
| MIME | Multipurpose Internet Mail Extensions (tipo de mídia de um arquivo) |
| MVC | Model-View-Controller |
| PDF | Portable Document Format |
| PK | Primary Key (chave primária) |
| PNG | Portable Network Graphics |
| R2 | Cloudflare R2 (armazenamento de objetos usado para as mídias) |
| RAG | Retrieval-Augmented Generation (geração aumentada por recuperação) |
| RF | Requisito funcional |
| RIPD | Relatório de Impacto à Proteção de Dados Pessoais |
| RNF | Requisito não funcional |
| ROPA | Registro das Operações de Tratamento de Dados Pessoais |
| SSE | Server-Sent Events |
| TC | Caso de teste |
| TDD | Technical Design Document (documento de design técnico) |
| UC | Caso de uso (use case) |
| UML | Unified Modeling Language |
| URL | Uniform Resource Locator |
| US | Estória de usuário (user story) |
| UUID | Universally Unique Identifier |
| WCAG | Web Content Accessibility Guidelines |
