# 7 RELAÇÃO DE ESTÓRIAS DE USUÁRIO

O template exige uma estória de usuário por requisito funcional, com critérios de aceite. Formato Como / Posso / Para, com pelo menos 2 critérios (ADR-0002).

O conteúdo fica nos arquivos area-a.md a area-d.md, nessa ordem. Os IDs provisórios por área são renumerados em sequência única antes da revisão final (ADR-0001).
